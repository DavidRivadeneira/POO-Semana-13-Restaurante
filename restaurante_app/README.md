# Restaurante App · Semana 13

**Juan David Rivadeneira Cuascota · Universidad Estatal Amazónica**

**Programación Orientada a Objetos · Segundo semestre · Paralelo F**

Base gráfica con Tkinter para iniciar una sesión simulada y consultar productos
y usuarios mediante servicios y archivos JSON locales.

Desde esta carpeta:

```powershell
python main.py
```

En Windows también puede utilizarse `py main.py`.

Acceso de demostración: usuario **ana**, contraseña **1234**.

Flujo: **Login → Panel principal → Productos / Usuarios → Cerrar sesión → Login**.
La opción **Ventas (pendiente)** presenta un aviso de desarrollo futuro.

Consultar el [README principal](../README.md) para los datos académicos, la
estructura, responsabilidades, continuidad con Semana 12 y comprobación.
